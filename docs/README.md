## What is Raichu?
Raichu is a web-based strategy game combining Chess and Pokemon mechanics. It features:
-   **Single Player**: Play against a Minimax AI.
-   **Local Multiplayer**: Two players on one device.
-   **Online Multiplayer**: Real-time play across devices using Supabase & polling.
